# Student Portal

![Flutter](https://img.shields.io/badge/Flutter-02569B?logo=flutter&logoColor=white)
![Dart](https://img.shields.io/badge/Dart-0175C2?logo=dart&logoColor=white)

A Flutter application implementing a clean authentication flow with Login, Registration, and Welcome homepage for Lab Activity 3.

## Features

- Material Design 3 interface with maroon and white styling
- User registration with input validation and password confirmation
- Secure login flow with password visibility toggle
- Welcome homepage displaying registered user details
- Single in-memory account session management

## Getting Started

```bash
flutter pub get
flutter run
```
